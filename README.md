# Better Pottery Craft

Better Pottery Craft 是一个以现实陶器制作流程为灵感的 Minecraft Java 版 Fabric 模组。它在保留原版内容的基础上，加入陶泥、陶轮、陶窑、分阶段烧制与釉料，让玩家可以制作不同器型和颜色的陶器。

> 当前为早期测试版 `v1.0.0-beta.1`。此版本重点验证陶艺制作流程；储物罐、花盆和花瓶目前是制作流程中的物品，尚未实现放置、储物栏或种植交互。

## 版本与依赖

- Minecraft Java：26.3
- 模组加载器：Fabric Loader 0.20.1 或更高版本
- 依赖：Fabric API（项目构建版本为 `0.166.2+26.3`）
- Java：25 或更高版本
- 许可：MIT

本项目仓库当前为私有仓库。下载 Release 需要 GitHub 账号拥有该仓库的访问权限。

## 模组内容

### 陶泥与颜色

把黏土球与沙子混合，制作可用于塑形的陶泥。基础配方产出 2 个本色陶泥；加入对应材料可以制作有色陶泥：

| 陶泥颜色 | 配方材料 |
| --- | --- |
| 本色 | 1 个黏土球 + 1 个沙子，产出 2 个 |
| 铁红 | 黏土球 + 沙子 + 粗铁 |
| 铁褐 | 黏土球 + 沙子 + 铁粒 |
| 铜绿 | 黏土球 + 沙子 + 粗铜 |
| 青金石蓝 | 黏土球 + 沙子 + 青金石 |
| 紫水晶紫 | 黏土球 + 沙子 + 紫水晶碎片 |
| 木炭黑 | 黏土球 + 沙子 + 木炭 |

这些配方是受矿物颜料启发的游戏化简化配方，并不模拟真实陶瓷化学。

### 陶轮塑形

陶轮可塑造三种器型：

- 储物罐
- 花盆
- 花瓶

空手使用陶轮可依次切换当前器型。手持一种陶泥对陶轮使用，会消耗 1 个陶泥并开始塑形；等待约 4 秒后，陶坯会作为物品出现在陶轮旁边。陶泥的颜色决定陶坯的坯体颜色。

### 陶窑烧制与上釉

陶器制作分为第一次烧制、施釉和复烧：

1. 将煤炭或木炭放入陶窑，为本次烧制提供燃料。
2. 放入未烧制的陶坯，等待约 10 秒，得到对应颜色的素烧陶器。
3. 在工作台中，将素烧陶器与同颜色的釉料合成施釉待复烧陶器。
4. 再次给陶窑加入煤炭或木炭，并放入施釉待复烧陶器。
5. 等待约 10 秒，得到最终的釉面陶器。

陶窑每次烧制消耗 1 个煤炭或木炭。当前窑炉采用右键交互和定时完成机制，不是原版熔炉界面。

### 釉料

无色釉料由黏土球、石英和沙子合成，产出 2 个。将无色釉料与着色材料合成可获得对应颜色的釉料：

| 釉料颜色 | 着色材料 |
| --- | --- |
| 无色 | 不需要着色材料 |
| 铁红 | 粗铁 |
| 铁褐 | 铁粒 |
| 铜绿 | 粗铜 |
| 青金石蓝 | 青金石 |
| 紫水晶紫 | 紫水晶碎片 |
| 木炭黑 | 木炭 |

施釉时，陶器器型、坯体颜色和釉料颜色必须对应；例如，铁红素烧花瓶需要与铁红釉料合成。

## 完整制作流程

```text
黏土球 + 沙子 (+ 着色材料)
          |
          v
       陶泥
          |
   陶轮选择器型并塑形
          |
          v
       陶坯
          |
      陶窑烧制
          |
          v
     素烧陶器
          |
   工作台 + 对应釉料
          |
          v
    施釉待复烧陶器
          |
      陶窑复烧
          |
          v
      釉面陶器
```

## 工作台合成

### 陶轮

```text
 空  木棍  空
木棍 黏土球 木棍
 空  石台阶 空
```

### 陶窑

```text
红砖 红砖 红砖
红砖 熔炉 红砖
红砖 红砖 红砖
```

### 陶艺指南

```text
黏土球 + 纸 -> 陶艺指南
```

玩家首次加入世界时也会获得一本陶艺指南。指南介绍陶泥、陶轮、烧制和上釉流程，可通过上述配方重新制作。

## 安装

1. 安装 Minecraft Java 26.3。
2. 安装兼容 Minecraft 26.3 的 Fabric Loader 和 Fabric API。
3. 下载本项目 Release 中的 `better-pottery-craft-1.0.0.jar`。
4. 将 JAR 文件放入 Minecraft 实例的 `mods` 文件夹并启动游戏。

[查看 v1.0.0-beta.1 Release](https://github.com/hktkMAX/Better_pottery_craft/releases/tag/v1.0.0-beta.1)

如果 Release 页面无法打开，请确认你的 GitHub 账号已获得私有仓库访问权限。

## 已知限制

- 储物罐、花盆、花瓶目前是物品，不可作为方块放置。
- 储物罐尚无物品存储界面或容量功能。
- 花盆尚无种植交互，花瓶尚无插花交互。
- 陶轮和陶窑是基础方块交互，目前没有专用 GUI。
- 这是测试版，建议在测试前备份存档；后续版本可能调整配方与玩法。

原版陶器内容不会被移除或替换；本模组提供的是额外的陶艺制作路线。

## 从源码构建

需要 JDK 25。Windows 下在 `code` 目录运行：

```powershell
cd code
.\gradlew.bat build
```

构建产物位于 `code/build/libs/`。
